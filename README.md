# Tenrai Improvement Proposals

Tenrai Improvement Proposals (TIPs) specify changes to consensus rules, networking, public APIs and shared protocol standards. Voluntary software conventions are defined by the [Tenrai Calls for Conventions](https://github.com/Tenrai-Technologies-Official/tenrai-tcc).

## Proposals

Open an issue to discuss the change. Use [the template](TEMPLATE.md) to submit a draft as `tip-draft-<name>.md`. Maintainers assign a number and rename it to `tip-<number>.md` when it enters Review.

A proposal moves from Review to Accepted or Rejected. A complete, implemented proposal becomes Final once activated where applicable. Authors may withdraw a proposal.

A consensus TIP specifies deterministic behavior and its activation conditions. An accepted change takes effect at the height in the network's rule schedule once node operators and validators deploy the corresponding release. The schedule retains the chain's genesis.
